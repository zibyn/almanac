# 只追加的事件日志是唯一事实来源，记忆正文不可变，更新即取代

almanac 的状态全部由一份只追加的事件日志表达：写入证据、记录记忆、附证、取代、撤回都是事件，记忆的状态（生效 / 被取代 / 撤回 / 无据）由事件推导，索引和缓存都可从日志重建。记忆写入后正文不再修改，「更新」就是记一条新记忆取代旧的，旧记忆和它的证据留在取代链上。这样每条记忆为什么是现在这个样子都可追溯，也让「记忆会变，证据永存」成立。

## Considered Options

- **可编辑记录（原地 UPDATE / 删除）**：实现最简单，但丢失历史，无法回答「之前为什么这么认为」，也无法区分被取代与被撤回。
- **嵌入式或外部数据库作为事实来源**：查询方便，但违背「不依赖外部数据库、存储为记忆特性定制」，库文件也不能直接阅读或 grep。

## Consequences

- 日志唯一的重写例外是清除（Purge），见 ADR 0001。
- 日志格式一旦有真实数据就很难更改；格式演进只能靠加字段或新事件类型，读端必须容忍未知字段。
- 遗忘只能表达为撤回，不能表达为删除。
