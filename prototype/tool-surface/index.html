almanac 智能体工具面草案PROTOTYPE · 用完即弃

问题：暴露给智能体的工具（MCP 与 CLI 共用同一套 schema）应该是哪几个、各长什么样，才能让智能体按 agentic search 的方式多轮检索，并且在写入门槛（必引证据、必填作用域与认知状态、取代/撤回/附证）下一次写对？ 左栏是 6 个工具的 schema 草案；右边可以直接调用（在内存里运行，刷新即清空），也可以按场景一步步走。 每次调用后，下方的状态面板会重新渲染，刚变化的行会高亮。

工具清单（草案）

共同约定：每个工具都接受可选的 project（路径，只用来定位）；不传时依次取 roots/list → CLAUDE_PROJECT_DIR → cwd。almanac 再由路径推出项目标识：在 git 仓库内时用 git（归一化的 origin remote，没有 remote 时用根提交），不在 git 内才退回路径。这样多台设备上同一个仓库是同一个项目。Writer 由 almanac 自动填写，不作为参数。CLI 与 MCP 同名：almanac search --json '{…}'。只在 CLI 提供：purge（清除）、context（会话开始注入，规格待定）。
